Privacy Policy

Last updated: 2026-10-04

This Privacy Policy explains how Podcast Studio ("the application") handles information. The application is operated by Nicolas Neveu (contact: nounoursnic11@gmail.com).

Use of YouTube API Services

The application uses YouTube API Services. By using it, users agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information accessed

With the user's permission, granted through Google sign-in (OAuth 2.0, scopes youtube.upload and youtube.force-ssl), the application accesses:

  • the basic details of the authorized channel (channel ID, title and avatar), to display which channel is connected;
  • the titles and IDs of the channel's playlists, so the user can choose a playlist;
  • the ability to upload videos, thumbnails and captions to that channel and to add videos to its playlists.

How information is used, stored and shared

  • Information is used only to publish the user's own videos to the user's own channel.
  • The OAuth access and refresh tokens are stored only on the user's own computer, in a local configuration file. There is no server, account system or database operated by the application.
  • The only YouTube data kept is the ID and URL of each video the application uploaded, stored locally with the corresponding episode.
  • No information is sold, shared with third parties or used for advertising. The application uses no cookies, no analytics and no tracking.

Revoking access

The user can disconnect the channel at any time with the "Disconnect" button in the application, which revokes the token, and can also revoke the application's access from the Google security settings page: https://myaccount.google.com/permissions.

Deleting data

All stored data stays on the user's computer and can be deleted by removing the application's local files. To request deletion or ask a question, contact nounoursnic11@gmail.com; requests are handled within 7 days.

Changes

Any change to this policy will be published on this page with a new date.
